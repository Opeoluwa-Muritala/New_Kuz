# 💬 KUZ Chat App

A real-time messaging app with end-to-end encryption, Firebase support, and a clean Jetpack Compose UI.

---

## 🔐 Features

- ✅ One-on-one real-time messaging
- ✅ Firebase Authentication and Firestore DB
- ✅ Encrypted chat storage with Room
- ✅ Modern UI with Material 3
- ✅ MVVM + Hilt + Clean Architecture

---

## 🧰 Tech Stack

- **Language**: Kotlin  
- **UI**: Jetpack Compose  
- **State Management**: ViewModel, LiveData  
- **Database**: Firebase Firestore + Room (Encrypted)  
- **DI**: Hilt  
- **Testing**: JUnit, Espresso, Mockito
